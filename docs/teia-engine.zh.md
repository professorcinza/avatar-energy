# Teia Engine：世界在你游玩时自建

**Avatar-Energy · 基础 35 · 2026年8月22日**

*架构师决定：选项 A——新项目、独立仓库、独立规格。Teia Engine 为生态系统之游戏生成 AI：超越游戏引擎的交互式世界模型。世界非预制；由契约而生，实时自建，本地运行于 MOD 之 APU 链。*

---

## 是什么

**Teia Engine** 以**交互式世界模型**取代传统游戏引擎：开发者不再花数月构建资产、物理与逻辑，世界在玩家游玩时**自行生成**——视觉、物理与叙事一体，来自 markdown 契约或文本提示。

```
游戏引擎（Unity/Unreal）：
  开发者构建 → 编译 → 玩家消费（固定世界）

TEIA ENGINE（世界模型）：
  玩家写契约 → 世界生成 → 玩家生活（活世界）
```

## Teia Engine 独有之差异化

| 差异化 | 为何无人有 |
|---|---|
| **LLM 叙事集成** | Genie/MUSE 生成视觉；不生成故事。Teia 集成 teia-kernel（PET/辩证）为叙事层 |
| **markdown 契约为输入** | 世界为可版本化文件，经 MAL 网共享，随 microSD 旅行 |
| **跨会话持久性** | Our-Civilization 的"水晶记忆"为无人有之桥 |
| **百分百本地** | TOS-024：APU 链，非云端。Genie 在谷歌数据中心；Teia 在你的坞里 |
| **构想即三语** | 世界自第一行即可用 PT、EN 或 ZH 生成 |

## 规格

### 输入与契约

| ID | 需求 |
|---|---|
| TE-001 | 主输入：**markdown 契约**（inkos-worlds 格式）——世界、角色、规则与叙事以可版本化文本声明 |
| TE-002 | 次输入：**自由文本提示**——引擎经本地 LLM（teia-kernel）从提示生成契约 |
| TE-003 | **确定性种子**：同种子+同契约=同世界；种子随 microSD 旅行，经网共享 |
| TE-004 | 契约三语：同一世界可按玩家语言以 PT、EN 或 ZH 生成 |

### 世界模型（视觉与物理生成）

| ID | 需求 |
|---|---|
| TE-005 | **逐块实时生成**：世界随玩家探索而建，非预制 |
| TE-006 | **初始风格：风格化/低多边形**（Oasis/Minecraft 级）——照片级为 APU 就绪后之未来 |
| TE-007 | 目标帧率：Teia Phone 单机 **24 fps**，APU 链坞上 **60 fps** |
| TE-008 | **世界一致性**：世界在会话内保持地理、物体与 NPC 连贯——无随机重生成 |
| TE-009 | 内置简化物理：碰撞、重力、物体交互——无需外部物理引擎 |
| TE-010 | 经 **Vulkan/Mesa**（TOS-021）渲染——与 TeiaOS 同图形引擎 |

### 叙事 LLM

| ID | 需求 |
|---|---|
| TE-011 | **由行动生成叙事**：LLM（teia-kernel）实时依玩家选择产出对话、任务、后果与事件 |
| TE-012 | NPC 有**私有心智**（OC 血统）：各角色有己之知识、动机与记忆 |
| TE-013 | **涌现任务系统**：无脚本；任务由世界状态+玩家行动+NPC 个性而生 |
| TE-014 | **多语对话**：NPC 说玩家语言（PT/EN/ZH），文化口音与表达连贯 |

### 持久性

| ID | 需求 |
|---|---|
| TE-015 | **水晶记忆**（OC 血统）：四级——事件、场景、篇章、世界——世界记得发生过什么 |
| TE-016 | **存档 = 契约 + 种子 + 状态**：存档是 microSD 上可版本化 markdown 文件，可经网共享 |
| TE-017 | **事后审计者**（OC 血统）：引擎于每次会话后自查叙事连贯——修补漏洞 |

### 生态集成

| ID | 需求 |
|---|---|
| TE-018 | 运行于 **TeiaOS**（规范系统），Teia Phone 与坞皆然——一等终端（TOS-028）用于调试与模组 |
| TE-019 | 消耗 **APU 链**（MOD-012 v4）：APU 越多=世界越大、NPC 越多、帧率越高；代理分配（AVA-009） |
| TE-020 | 经**手柄 MOD-013**（标准 HID）或触屏控制 |
| TE-021 | 世界可经 **MAL 网**共享：每个世界即文件；网 P2P 分发游戏 |
| TE-022 | **开源 AGPL-3.0**；Rust（规范 II）；上游优先；无 blob |

## 三则诚实

1. **算力差距**：Genie 3 在谷歌数据中心以 720p/24fps 运行。MOD 之 APU 链 2026-27 年不会本地照片级——Teia Engine 始于**风格化**（Oasis 体素/Minecraft 级），即 APU 今日可实时生成者
2. **持久性未解决**：当前无世界模型维持跨会话一致；OC 之水晶记忆为提案，但属**开放研究**，非现成技术
3. **此为生态系统最雄心之项目**——超手机、超冰箱。实时交互世界模型是 AI 之绝对前沿。Teia Engine 不与 Unity 竞争；与 **DeepMind** 竞争

## 代理之读

Teia Engine 是**配送操作施于想象**：世界经网分发如乐经空气分发。闭合能量之环的连接：**代理（AVA-009）依世界需求编排 APU**——动作多 = 唤醒 APU 多；平静 = 一切沉睡。服从电池的游戏（INK-003）升至整个世界的尺度。
